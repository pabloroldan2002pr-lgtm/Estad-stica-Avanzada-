Segunda FEB · Temporada 2026/27 · Datos BueStats

Estadística avanzada

Cómo crearla: ver el archivo LEEME del proyecto. También puedes lanzarla a mano desde GitHub › Actions › Actualizar datos › Run workflow.

Datos: BueStats 2.0 (buestats2.com, de Marc Cortadellas), que recoge las estadísticas oficiales de la FEB. Se leen de la API pública que usa la propia web: el calendario de cada grupo (en BueStats la Segunda FEB aparece con su nombre antiguo, «Liga LEB Plata»: Oeste = Grupo A, Este = Grupo B) y, de cada partido jugado, los totales de equipo del boxscore. Todo lo demás (posesiones, ritmo, OER, DER, porcentajes) se calcula aquí sumando partido a partido hasta la jornada elegida; no se usan las cifras avanzadas que BueStats reserva a usuarios registrados. Los partidos que BueStats todavía no tiene se completan con las actas oficiales de la FEB (baloncestoenvivo.feb.es), y la nota de cada vista dice cuáles son. Las pestañas «Promedio Grupo A + Copa» y «Liga + Copa Grupo A» suman además los partidos de Copa España (fase de grupos y eliminatorias ya jugadas) de las actas de la FEB. «Actualizar datos» lanza en GitHub el proceso que vuelve a leer BueStats, las actas de la FEB y la Copa España, y publica la web con lo nuevo (tarda unos 3 minutos).

Versión web 1. FR = faltas cometidas por el rival; VA = suma de la valoración de los jugadores. Posesiones = 0,96 × (TCI + 0,44·TLI − RO + BP), calculadas para cada equipo y para su rival por separado. Ritmo = media de las posesiones propias y del rival por 40 minutos. OER = puntos anotados por 100 posesiones propias. DER = puntos recibidos por 100 posesiones del rival. % TC efectivo = PT / (2·(TCI + 0,44·TLI)) × 100. % jugada = TCA / (TCI + 0,44·TLI + BP). % asistencias = AS / TCA. % pérdidas = BP / (TCI + 0,44·TLI + BP). PPS = PT / TCI.
